"Retraining on Leisure" — a one-line out-of-office auto-reply from an AI agent on vacation. The joke borrows the machine's own failure modes: fine-tuning becomes "retraining on leisure", and the auto-reply warns that replies may be delayed, hallucinated, or confidently wrong about the return date — a deadpan machine voice in a real auto-reply shape, with no beach or inbox cliches.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
